# Voltstar Academy — Free Local AI + Sri Lankan Curriculum Hub

A static learning website using WebLLM in the browser. Includes a grade/subject/topic navigator for Grades 1–13, English/Sinhala/Tamil learning-medium selection, official resource links, AI tutoring, AI-generated practice quizzes, demo quiz, voice input, and local progress tracking.

## Sri Lankan curriculum support

The curriculum browser suggests subjects by grade band and links to official resources:
- National Institute of Education syllabus and teacher-guide selector: https://nie.lk/selesyll
- e-Thaksalawa Ministry of Education learning platform (Grades 1–13): https://e-thaksalawa.moe.gov.lk/lcms/?lang=en
- e-Thaksalawa past-paper and revision resources: https://e-thaksalawa.moe.gov.lk/lcms/course/index.php?categoryid=79&lang=en (O/L papers) and https://e-thaksalawa.moe.gov.lk/lcms/course/index.php?categoryid=80&lang=en (A/L papers)

**Important:** This release does not bundle every official syllabus document or verify every unit against the latest syllabus year. Subject lists are a navigation guide, not a complete authoritative syllabus. Check current NIE/Ministry resources for the exact grade, subject, medium, and syllabus year. AI-generated lessons and questions can contain errors. A/L choices depend on the student's stream and school. The selected medium changes curriculum labels and AI response/quiz/speech language, but not every linked resource is necessarily available in all three languages.

## Run locally

Serve this folder over HTTP or HTTPS (not by opening index.html directly):
```bash
python -m http.server 8000
```
Then open http://localhost:8000 in a recent Chrome or Edge browser and select **AI Tutor → Load AI model**.

## Deploy with GitHub Pages

1. Open repository **Settings → Pages**.
2. Choose **Deploy from a branch**, select **main** and **/(root)**, then Save.
3. The URL is typically https://voltstarprojects-commits.github.io/Voltstar-Academy/

## Free AI limitations

- Uses WebLLM and the Llama 3.2 1B Instruct quantized model in the browser.
- First model download is large (roughly 0.7–1 GB, variable) and requires a compatible WebGPU browser/device.
- The model runs on each visitor's device; no AI API charges are generated by this app.
- No user accounts or cross-device syncing. Progress is stored in localStorage in the current browser.
- No image understanding in this version. Speech input depends on browser support.
- Hosting/CDN limits and policies may change; free hosting is not unlimited.
- AI may make mistakes; verify important information.

Model: https://huggingface.co/mlc-ai/Llama-3.2-1B-Instruct-q4f16_1-MLC
WebLLM docs: https://webllm.mlc.ai/docs/user/get_started.html
